# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Do not disclose a security or input-lockout vulnerability in a pull request, commit comment, or public discussion.

Use GitHub's private **Report a vulnerability** feature on the repository's [Security tab](https://github.com/allcapsjoe/nulea-mouse-mapper/security/advisories/new).

Include:

- the affected Windows version;
- the mouse connection type and relevant non-personal VID/PID information;
- the smallest reproducible sequence;
- whether input was blocked and how it was recovered;
- any proposed mitigation.

Never include a personal device handle, account token, machine name, or other sensitive identifier.
